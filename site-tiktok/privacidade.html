Política de Privacidade

Fábrica, ferramenta pessoal de produção de vídeos

InícioTermos de ServiçoPolítica de Privacidade

1. Quais dados são usados

Ao conectar uma conta do TikTok ou do YouTube, a ferramenta recebe um token de acesso que permite enviar vídeos para essa conta. Nenhum outro dado pessoal é coletado.

2. Onde ficam os dados

O token fica armazenado apenas no computador do criador, em um arquivo local. A ferramenta não possui servidor próprio, banco de dados em nuvem nem rastreadores.

3. Compartilhamento

Os dados não são vendidos, compartilhados nem transferidos a terceiros. Eles são enviados somente às próprias plataformas (TikTok e YouTube) para realizar o envio autorizado dos vídeos.

4. Como remover o acesso

O criador pode desconectar a conta no próprio programa, que apaga o token local, e também revogar a autorização nas configurações de segurança e permissões do TikTok e da conta Google.
